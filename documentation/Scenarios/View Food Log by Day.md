View Food Log by Day

Actor

User



Preconditions

User is logged in.



Main Flow

1. User navigates to the dashboard.
2. User selects a date from datepicker.
3. System retrieves food and meal items recorded for that date.
4. System displays the items along with nutritional totals.



Alternate Flows



No Items Logged

* If no items are recorded for the selected date, the system displays an empty log message.



Postconditions

The user can review the foods and meals consumed on a given day.
