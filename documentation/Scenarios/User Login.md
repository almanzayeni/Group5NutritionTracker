**User Login**

*Actor*

User



*Preconditions*

User already has an account.



*Main Flow*

1. User runs application.

2\. User enters their username and password.

3\. User submits login credentials.

4\. Server validates credentials and sends response.

5\. System logs the user in.

6\. System displays the user's dashboard.



*Alternate Flows*

4a. Invalid Credentials

* System displays an error message.
* User is prompted to re-enter credentials.



*Postconditions*

User is authenticated, app is populated with their data, load landing page.
