View Remaining Nutrition for the Day

Actor

User



Preconditions

User is logged in.

User has a diet plan configured.



Main Flow

1. User navigates to the dashboard.
2. System retrieves the user’s diet plan goals.
3. System retrieves the food items logged for the day.
4. System calculates the consumed nutrition values.
5. System calculates the remaining calories and nutrition values.
6. System displays a visual and string of remaining values to the user.



Alternate Flows

No Diet Plan Exists

* If no diet plan exists, the system informs the user.
* The user is prompted to create a diet plan.



Postconditions

The user can view how much nutrition they have remaining for the day.
