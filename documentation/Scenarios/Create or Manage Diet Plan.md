**Create or Manage Diet Plan**

*Actor*

User



*Preconditions*

User is logged into the system.



*Main Flow*



1. User navigates to the diet plan section, near account settings.

2\. User selects the option to create or edit a diet plan.

3\. User enters nutritional goals such as calories and other nutrition values.

4\. User submits the diet plan.

5\. System validates the input values.

6\. System saves the diet plan.

7\. System confirms the diet plan has been saved.



*Alternate Flows*

Invalid Input

If the input values are invalid, the system displays validation errors.

The user corrects the values and resubmits the plan.



*Postconditions*

The user’s diet plan is stored in the server and used for nutritional tracking.
